# Data files

Files in this folder represent the input data used by the PCA and word2vec
analysis workflows: filtered motif CSVs (`motifs_en_filtered.csv`,
`motifs_de_filtered.csv`, `motifs_media_filtered.csv`) and NER data
(`qanon_ner.csv`, `media_ner.csv`).

Large upstream text-processing exports, cleaned word2vec training CSVs, and
trained word2vec model files are not included in the repository. They are either
regenerated by the scripts under `w2v/` or available on request.
